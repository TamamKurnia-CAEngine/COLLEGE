# Supervised Learning - Classification

Repository ini berisi materi hands-on project untuk klasifikasi menggunakan machine learning dengan algoritma **Logistic Regression** dan **K-Nearest Neighbors (KNN)**.

## Deskripsi
Notebook ini (`Supervised_Learning_Hands_On_Classification.ipynb`) berisi langkah-langkah implementasi model klasifikasi, mulai dari persiapan data hingga prediksi data baru.

Tahapan yang ada di dalam project ini:
1. **Preparation**: Import library (Pandas, Numpy, Seaborn, Matplotlib, Scikit-Learn).
2. **Data Exploration**: Memahami dataset yang digunakan.
3. **Preprocessing**: Menyiapkan data agar siap diproses oleh model.
4. **Modeling**:
   - Menggunakan **Logistic Regression** sebagai model dasar.
   - Menggunakan **K-Nearest Neighbors (KNN)** untuk klasifikasi.
5. **Evaluation**: Mengukur performa model menggunakan *Confusion Matrix* dan *Classification Report*.
6. **Prediction**: Mencoba memprediksi data baru menggunakan model yang sudah dilatih.

## Library yang Dibutuhkan
Pastikan library berikut sudah terinstall:
- `pandas`
- `numpy`
- `matplotlib`
- `seaborn`
- `scikit-learn`

## Cara Penggunaan
1. Upload file `.ipynb` ke **Google Colab** atau buka menggunakan **Jupyter Notebook** lokal.
2. Jalankan sel kode satu per satu secara berurutan.
3. Gunakan bagian evaluasi untuk melihat seberapa akurat model dalam melakukan klasifikasi.
