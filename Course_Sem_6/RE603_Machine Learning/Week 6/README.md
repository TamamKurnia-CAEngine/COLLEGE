# Supervised Learning - Classification (Titanic Survival)

Repository ini berisi proyek latihan **Supervised Learning** untuk mengklasifikasi data penumpang (berdasarkan dataset Titanic) menggunakan algoritma **Logistic Regression** dan **K-Nearest Neighbors (KNN)**.

## Deskripsi Project
Tujuan dari project ini adalah untuk memprediksi apakah seorang penumpang selamat (1) atau tidak selamat (0) berdasarkan fitur-fitur yang tersedia dalam dataset.

**Alur Kerja:**
1. **Preparation**: Memanggil library yang diperlukan seperti `pandas`, `numpy`, `seaborn`, dan `scikit-learn`.
2. **Exploratory Data Analysis (EDA)**: Melihat gambaran umum data dan distribusinya.
3. **Data Preprocessing**: Membersihkan data dan menyiapkan fitur untuk pemodelan.
4. **Modeling**:
   - Membangun model dengan **Logistic Regression**.
   - Membangun model dengan **K-Nearest Neighbors (KNN)**.
5. **Evaluation**: Mengevaluasi performa kedua model menggunakan *Confusion Matrix* dan *Classification Report*.
6. **Prediction**: Mencoba memprediksi data penumpang baru menggunakan model yang telah dilatih.

## Library yang Digunakan
- `pandas`
- `numpy`
- `matplotlib`
- `seaborn`
- `scikit-learn`

## Cara Menjalankan
